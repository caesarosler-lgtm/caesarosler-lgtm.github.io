개인정보처리방침

나의도서관 · 시행일 2026년 10월 7일

1. 어떤 정보를 다루나요

나의도서관은 사용자의 컴퓨터에서만 동작하는 개인용 프로그램입니다. 사용자가 입력한 내용은 사용자의 컴퓨터에 저장되며, 개발자를 포함한 누구에게도 전송되지 않습니다.

2. Google 사용자 데이터의 사용

  • 사용자가 직접 연결한 경우에만, 프로그램이 만든 백업 파일(zip)을 사용자 본인의 Google 드라이브에 올리고, 오래된 백업을 정리하며, 올라간 파일이 온전한지 확인합니다.
  • 권한은 drive.file(이 프로그램이 만든 파일만)으로 한정되어, 드라이브의 다른 파일은 읽거나 바꿀 수 없습니다.
  • Google에서 받은 정보는 위 목적 외에 쓰지 않으며, 다른 곳에 전송 · 판매 · 공유하지 않습니다. 광고나 분석에 쓰지 않습니다.
  • 연결 열쇠는 사용자 컴퓨터의 Windows 자격 증명 관리자에만 보관됩니다.

Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 연결 해제와 삭제

프로그램의 백업 센터에서 언제든 연결을 해제할 수 있고, Google 계정의 서드파티 액세스에서도 권한을 취소할 수 있습니다. 드라이브의 '나의도서관 백업' 폴더를 지우면 백업도 모두 지워집니다.

Privacy Policy (English summary)

나의도서관 ("My Library") is a personal desktop app that runs only on its user's computer. Content stays on that computer and is never sent to the developer or third parties. When the user connects a Google account, the app uses the drive.file scope solely to upload, prune and verify its own backup zip in the user's own Google Drive. Google user data is not transferred, sold, shared, or used for advertising or analytics, and its use complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in the app or at myaccount.google.com/permissions.
